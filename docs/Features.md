# CareerCompass AI Features

## Overview

CareerCompass AI is an AI-powered career guidance platform that assists students and professionals in career planning, resume building, job searching, and skill development.

---

# Core Features

## 1. User Authentication

- User Registration
- Email Verification (OTP)
- Login
- Google OAuth Login
- Forgot Password
- Reset Password
- JWT Authentication

---

## 2. AI Career Assessment

- 40 Personality Questions
- AI Personality Analysis
- Top Career Recommendations
- Career Strength Analysis

---

## 3. Career Library

- Browse Careers
- Search Careers
- Career Details
- AI Career Advisor

---

## 4. Professional Profile

Users can manage:

- Personal Information
- Education
- Experience
- Skills
- Certifications
- Career Preferences

Profile completion percentage is calculated automatically.

---

## 5. Resume Builder

Features include:

- Multiple Resume Templates
- AI Summary Generation
- AI Experience Enhancement
- ATS Score
- Live Preview
- PDF Export

---

## 6. Job Search

- Live Job Listings
- Save Jobs
- AI Match Score
- Job Tracker
- Application Status Updates

---

## 7. Learning Path Generator

AI generates personalized learning plans containing:

- Learning Phases
- Topics
- Courses
- Certifications
- YouTube Resources

Progress is tracked as users complete topics.
